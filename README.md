# Psychometric Representation Learning

Code for evaluating representation learning objectives using linked teacher-child psychometric data.

## Overview

This project uses 757 matched teacher-child pairs from the baseline assessment of the Cyprus ProW preschool trial to compare PCA-based, contrastive, and multi-task representations.

We evaluate two aspects of the learned representations:

* Teacher-child retrieval
* Behavioral phenotype preservation

Results show that contrastive learning improves teacher-child retrieval but preserves behavioral structure less effectively than PCA-based representations. Multi-task learning partially restores behavioral organization while reducing retrieval performance.

## Data

Participant-level data are not included due to data access and privacy restrictions.
